4.1 Testing layers against references

Chapter 1 checked each layer once, on one input. Real tests check many shapes against an independent reference, with metrics that tell a rounding difference from a bug. This section builds the pattern MAX uses for its own layers, in max/python/layer_benchmarks, and applies it to your decoder layer, with Hugging Face’s PyTorch Llama as the reference.

How to compare outputs

One number is not enough. MAX’s test harness reports three:

  • The maximum absolute error catches any single element that is far off.
  • The mean absolute error is the typical error, which tells a few outliers from a systematic drift.
  • The cosine distance, \(1 - \cos\theta\) between the flattened outputs, is near 0 when the outputs point the same way even if their scale differs slightly, and large for a structural bug such as a wrong head layout.

A test passes when the outputs are allclose, within an absolute and a relative tolerance, and the cosine distance is below a threshold. The defaults below, 1e-3 for both tolerances and 1e-5 for the cosine distance, are tighter than MAX’s (1e-2 and 1e-3) because every test here runs in float32; MAX’s bfloat16 layer tests loosen them further.

from __future__ import annotations

from dataclasses import dataclass

import numpy as np


@dataclass
class CorrectnessResult:
    """How far an output is from its reference, as MAX's layer tests report it."""

    label: str
    mae: float
    max_abs_err: float
    cos_dist: float
    passed: bool

    def __str__(self) -> str:
        status = "pass" if self.passed else "FAIL"
        return (
            f"{self.label:16} mae {self.mae:.1e}  max {self.max_abs_err:.1e}  "
            f"cos dist {self.cos_dist:.1e}  {status}"
        )


def compare_outputs(
    actual: np.ndarray,
    expected: np.ndarray,
    label: str = "",
    atol: float = 1e-3,
    rtol: float = 1e-3,
    cos_threshold: float = 1e-5,
) -> CorrectnessResult:
    """Compares ``actual`` with ``expected``; passes when they are allclose
    and their cosine distance is below ``cos_threshold``."""
    a = actual.astype(np.float64).ravel()
    e = expected.astype(np.float64).ravel()
    cos_dist = 1.0 - float(
        a @ e / (np.linalg.norm(a) * np.linalg.norm(e) + 1e-12)
    )
    allclose = bool(np.allclose(actual, expected, atol=atol, rtol=rtol))
    return CorrectnessResult(
        label=label,
        mae=float(np.mean(np.abs(a - e))),
        max_abs_err=float(np.max(np.abs(a - e))),
        cos_dist=cos_dist,
        passed=allclose and cos_dist < cos_threshold,
    )

The reference

Hugging Face’s LlamaDecoderLayer is an independent implementation of the same layer, in PyTorch. Its parameter names match yours, so the same checkpoint entries load into both. "eager" selects its plain attention code instead of a fused kernel, so the reference stays simple.

hf_config = AutoConfig.from_pretrained(MODEL_ID, attn_implementation="eager")
reference = LlamaDecoderLayer(hf_config, layer_idx=0).float().eval()
reference.load_state_dict(
    {name: torch.from_numpy(w.copy()) for name, w in layer0.items()}
)
rotary = LlamaRotaryEmbedding(hf_config)


def reference_layer(x: np.ndarray) -> np.ndarray:
    batch, seq, _ = x.shape
    hidden = torch.from_numpy(x)
    positions = torch.arange(seq).expand(batch, seq)
    mask = torch.full((seq, seq), float("-inf")).triu(1)[None, None]
    with torch.no_grad():
        out = reference(
            hidden,
            attention_mask=mask,
            position_ids=positions,
            position_embeddings=rotary(hidden, positions),
        )
    return out.numpy()

Compile once, test many shapes

MAX’s harness separates static parameters, which fix the graph (here, the layer’s sizes), from dynamic ones, which vary per run (batch size and sequence length). Compile once with symbolic dimensions, then run every shape through the same compiled layer. The shapes cover the edges: a single token (a decode step), odd lengths, a batch, and a long prefill.

def compiled_layer(layer_class=DecoderLayer, weights=layer0, cfg=config):
    with F.lazy(), default_device(DEVICE), default_dtype(DType.float32):
        layer = layer_class(cfg)
    layer.load_state_dict(weights)
    return layer.compile(
        TensorType(
            DType.float32, ("batch", "seq_len", cfg.hidden_size), device=DEVICE
        )
    )


SHAPES = [(1, 1), (1, 7), (2, 33), (1, 512)]


def check(run, shapes=SHAPES) -> list:
    rng = np.random.default_rng(0)
    results = []
    for batch, seq in shapes:
        x = rng.standard_normal((batch, seq, config.hidden_size)).astype(
            np.float32
        )
        actual = run(Tensor(x, device=DEVICE)).to_numpy()
        results.append(
            compare_outputs(
                actual, reference_layer(x), label=f"batch {batch}, seq {seq}"
            )
        )
    return results


correct = check(compiled_layer())
for result in correct:
    print(result)
assert all(r.passed for r in correct)

A test must be able to fail

A test that never fails proves nothing, so check that this one catches a real bug. A plausible one is a config read wrong, with the base of RoPE (Section 1.4) at Llama 2’s 10000 instead of SmolLM2’s 100000:

Each point is one shape, labeled batch/sequence length, and an x marks a failure. The shaded corner is where both checks pass; its right edge is only approximate, because allclose also allows a relative error of 1e-3 of each expected value.

The single-token case still passes: at position 0, RoPE doesn’t rotate at all, so the bug can’t show there. Every longer input fails. The maximum error grows by two to four orders of magnitude and breaks the allclose check. The cosine distance grows by six to eight orders of magnitude, but it crosses its 1e-5 threshold only on the 512-token input. The two checks catch different bugs, which is why the test uses both, and why the shape list must include sequences, not just one token.

As a pytest file

In a repository, these checks belong in a test file that runs on every change. %%writefile saves a cell as a file. The test compiles the layer once per module, as MAX’s own tests do, and checks every shape:

%%writefile test_decoder_layer.py
import numpy as np
import pytest
import torch
from max.dtype import DType
from max.graph import TensorType
from max.tensor import Tensor, default_device, default_dtype
from transformers import AutoConfig
from transformers.models.llama.modeling_llama import LlamaDecoderLayer, LlamaRotaryEmbedding

from minillm.config import MODEL_ID, LlamaConfig
from minillm.device import pick_device
from minillm.model import DecoderLayer
from minillm.testing import compare_outputs
from minillm.weights import load_checkpoint, select

CONFIG = LlamaConfig.from_pretrained()


@pytest.fixture(scope="module")
def layers():
    weights = select(load_checkpoint(), "model.layers.0.")
    with default_device(pick_device()), default_dtype(DType.float32):
        ours = DecoderLayer(CONFIG)
    ours.load_state_dict(weights)
    compiled = ours.compile(
        TensorType(DType.float32, ("batch", "seq_len", CONFIG.hidden_size), device=pick_device())
    )
    hf_config = AutoConfig.from_pretrained(MODEL_ID, attn_implementation="eager")
    reference = LlamaDecoderLayer(hf_config, layer_idx=0).float().eval()
    reference.load_state_dict({k: torch.from_numpy(v.copy()) for k, v in weights.items()})
    return compiled, reference, LlamaRotaryEmbedding(hf_config)


@pytest.mark.parametrize("batch, seq", [(1, 1), (1, 7), (2, 33)])
def test_decoder_layer_matches_reference(layers, batch, seq):
    compiled, reference, rotary = layers
    x = np.random.default_rng(seq).standard_normal((batch, seq, CONFIG.hidden_size)).astype(np.float32)
    hidden, positions = torch.from_numpy(x), torch.arange(seq).expand(batch, seq)
    mask = torch.full((seq, seq), float("-inf")).triu(1)[None, None]
    with torch.no_grad():
        expected = reference(hidden, attention_mask=mask, position_ids=positions,
                             position_embeddings=rotary(hidden, positions)).numpy()
    result = compare_outputs(compiled(Tensor(x, device=pick_device())).to_numpy(), expected)
    assert result.passed, result
