5.4 Prefix caching

Real traffic repeats itself. Requests to a chat product start with the same system prompt, and every turn of a conversation resends the turns before it. Those shared tokens get the same keys and values every time, because a token’s keys and values depend only on that token and the tokens before it. Prefix caching computes them once and shares their cache blocks between requests. With the paged cache from Section 5.3, it takes little code.

Naming blocks by their content

To share a block, the engine must recognize it. A full block is identified by the tokens it holds and every token before it, since those determine its keys and values. A chained hash captures both: each block’s hash combines the previous block’s hash with the block’s own tokens. Two requests share a block exactly when their prompts agree up to the end of that block.

The pool keeps a table from hash to block, counts how many sequences use each block, and frees a block only when no sequence uses it. A block with no users whose contents are still valid stays in the table, in least-recently-used order, so a later request can still reuse it. Such blocks are evicted only when the pool runs out of free blocks.

Only full blocks are shared, and new tokens always go into a sequence’s own next block, so a shared block is never written to.

from __future__ import annotations

from collections import OrderedDict

from minillm.config import LlamaConfig
from minillm.paged import BlockPool, PagedCache, PagedEngine
from minillm.step import Request


class PrefixCachingPool(BlockPool):
    """A block pool that remembers full prompt blocks for reuse."""

    def __init__(
        self, config: LlamaConfig, num_blocks: int, block_size: int = 16
    ) -> None:
        super().__init__(config, num_blocks, block_size)
        self.refs = [0] * num_blocks
        self.by_hash: dict[int, int] = {}
        self.hash_of: dict[int, int] = {}
        self.unused: OrderedDict[int, None] = OrderedDict()  # cached, no users

    def allocate(self) -> int:
        if self.free:
            block = self.free.pop()
        elif self.unused:
            block, _ = self.unused.popitem(last=False)  # evict the oldest
            del self.by_hash[self.hash_of.pop(block)]
        else:
            raise MemoryError("the KV cache pool is full")
        self.refs[block] = 1
        return block

    def available(self) -> int:
        # Cached blocks that no request uses can be evicted and reused.
        return len(self.free) + len(self.unused)

    def release(self, blocks: list[int]) -> None:
        # Tail first: eviction then takes a prefix's last block before its
        # first, and lookup can still reuse the rest.
        for block in reversed(blocks):
            self.refs[block] -= 1
            if self.refs[block] == 0:
                if block in self.hash_of:
                    self.unused[block] = None
                else:
                    self.free.append(block)

    def block_hashes(self, tokens: list[int]) -> list[int]:
        hashes, previous = [], 0
        for start in range(
            0, len(tokens) - self.block_size + 1, self.block_size
        ):
            previous = hash(
                (previous, tuple(tokens[start : start + self.block_size]))
            )
            hashes.append(previous)
        return hashes

    def lookup(self, prompt: list[int]) -> list[int]:
        """Returns the cached blocks that start ``prompt``, and claims them.
        The last prompt token is always left to compute, since its logits
        are needed."""
        blocks = []
        for h in self.block_hashes(prompt[:-1]):
            block = self.by_hash.get(h)
            if block is None:
                break
            self.refs[block] += 1
            self.unused.pop(block, None)
            blocks.append(block)
        return blocks

    def register(self, prompt: list[int], blocks: list[int]) -> None:
        """Records a sequence's full prompt blocks for later requests."""
        # The last block may be partial; only full blocks have hashes.
        for h, block in zip(self.block_hashes(prompt), blocks, strict=False):
            if h not in self.by_hash:
                self.by_hash[h] = block
                self.hash_of[block] = h


class PrefixCachingEngine(PagedEngine):
    """A paged engine that skips computing prompt prefixes it has cached."""

    def __init__(self, *args, pool: PrefixCachingPool, **kwargs) -> None:
        super().__init__(*args, pool=pool, **kwargs)
        self.computed_prompt_tokens = 0

    def prefill_tokens(self, request: Request, cache: PagedCache) -> list[int]:
        tokens = (
            request.prompt + request.output
        )  # output is empty unless preempted
        cache.blocks = self.pool.lookup(tokens)
        cache.length = len(cache.blocks) * self.pool.block_size
        new = tokens[cache.length :]
        self.computed_prompt_tokens += len(new)
        return new

    def prefilled(self, request: Request, cache: PagedCache) -> None:
        self.pool.register(request.prompt, cache.blocks)

prefill_tokens and prefilled are the two hooks the engine from Section 5.2 calls around each prefill. The base engine returns the whole prompt from the first and does nothing in the second. The step model already handles the rest: a prefill with a non-empty past is a step with several new tokens.

def serve(engine) -> list[Request]:
    requests = workload()
    for r in requests:
        engine.add(r)
    start = time.perf_counter()
    engine.run()
    ttft = [(r.first_token - r.arrived) * 1000 for r in requests]
    print(
        f"{type(engine).__name__:24} {time.perf_counter() - start:5.1f} s   "
        f"TTFT median {np.median(ttft):5.0f} ms, worst {max(ttft):5.0f} ms"
    )
    return requests


class RecordingPrefixEngine(PrefixCachingEngine):
    """Records each request's computed tokens and its blocks' user counts."""

    def __init__(self, *args, **kwargs) -> None:
        super().__init__(*args, **kwargs)
        self.computed, self.tables = {}, {}

    def prefill_tokens(self, request: Request, cache: object) -> list[int]:
        tokens = super().prefill_tokens(request, cache)
        self.computed[id(request)] = len(tokens)
        return tokens

    def step(self) -> None:
        super().step()
        for request, cache in self.running:
            if id(request) not in self.tables:  # just prefilled
                self.tables[id(request)] = [
                    (b, self.pool.refs[b]) for b in cache.blocks
                ]

plain = serve(
    PagedEngine(step, config, DEVICE, max_batch=4, pool=BlockPool(config, 128))
)
prefix_pool = PrefixCachingPool(config, 128)
cached_engine = RecordingPrefixEngine(
    step, config, DEVICE, max_batch=4, pool=prefix_pool
)
cached = serve(cached_engine)

The first batch computes the system prompt once per request, because nothing is cached yet: requests 0 to 3 are prefilled in the same step, so each holds its own copy of the same blocks, and only request 0’s copy enters the table. From the second batch on, each request finds the system prompt’s full blocks in the table, the blue blocks four requests share, and computes only the rest: the system prompt’s last, partly filled block plus its own question. That brings the prompt tokens computed down to 715 of 1,291, or 55%. The outputs are identical, because the reused keys and values are exactly the ones the request would have computed.

The wall-clock gain is modest here: the whole workload took about 4.3 s with prefix caching against 5.1 s without, on this page’s machine (an Apple-silicon Mac with a Metal GPU), because prefilling about 160 prompt tokens on a 135M model is only part of the workload’s time. Treat these numbers as an example: yours depend on your hardware and vary from run to run. The saving grows with the shared prefix. A multi-turn chat resends the whole conversation so far on every turn, often thousands of tokens, and an agent resends long tool descriptions on every call, so for them prefix caching removes most of the prefill.

MAX Serve enables prefix caching by default; --no-enable-prefix-caching turns it off. The same idea extends across servers: a router can send each request to the replica that already holds its prefix. The handbook covers prefix caching and inference routing.
