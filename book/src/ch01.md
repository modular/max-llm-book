# 1. Foundations

This chapter goes from running a model to rebuilding it. You run and serve
SmolLM2-135M-Instruct with MAX, then rewrite it from scratch, one part per
section, until your version produces the same logits as MAX's and generates
text with a KV cache.

| Section                                                              | You learn                                                                                          |
|----------------------------------------------------------------------|----------------------------------------------------------------------------------------------------|
| [1.1 Run and serve an LLM](./01_01_run_and_serve.md)                 | `AutoPipeline`, `AutoModel`, `max generate`, `max serve`, and the two numbers that describe speed. |
| [1.2 Tensors and eager execution](./01_02_tensors_and_eager.md)      | `max.tensor`, `max.functional`, and `max.nn`: eager execution and compilation.                     |
| [1.3 Tokens, embeddings, and weights](./01_03_tokens_and_weights.md) | What a config and a checkpoint hold, and how to build the token embedding from them.               |
| [1.4 Building blocks](./01_04_building_blocks.md)                    | RMSNorm, the SwiGLU MLP, and rotary position embeddings.                                           |
| [1.5 Attention](./01_05_attention.md)                                | Causal grouped-query attention, first from basic operations and then with flash attention.         |
| [1.6 The full model](./01_06_full_model.md)                          | Assembling 30 layers and matching MAX's logits.                                                    |
| [1.7 Generation and sampling](./01_07_sampling.md)                   | The generation loop, temperature, top-k, and top-p.                                                |
| [1.8 The KV cache](./01_08_kv_cache.md)                              | Caching keys and values so that decoding stops redoing work.                                       |

Every section is a notebook that runs in a few minutes, on a GPU if you have
one and on a CPU otherwise. Sections 1.2 to 1.8 add code to the `minillm`
package as they go, so each section can start from the previous ones without
rerunning them.

By the end, you have a working LLM inference stack that you wrote yourself,
and you know the parts of MAX it is built from.
[Chapter 2](./ch02.md) splits that model across several devices.
